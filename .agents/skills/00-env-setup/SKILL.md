# 環境建置

1. 以 `agy --version`、`git --version`、`gh --version`、`node --version`、`npm --version`、`uv --version` 做唯讀快篩。
2. 只安裝任務真正需要且缺少的工具；先說明來源、影響與是否需系統管理員權限。
3. AntiGravity 2 登入或信任資料夾需使用者親自確認。
4. 驗收版本、登入狀態與一個 sandbox 唯讀任務；缺少選用工具不算失敗。
